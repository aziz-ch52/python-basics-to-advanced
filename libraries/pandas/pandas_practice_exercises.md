# Pandas Hands-On Practice Exercises

To truly master Pandas, you must write code. Reading about syntax will only get you so far. This document contains practical, scenario-based exercises aligned with the 10 core modules in this repository. 

**Instructions for Learners:**
1. Try to solve these problems without looking at the reference files first.
2. If you get stuck, refer back to the corresponding `0X_...py` module.
3. For exercises requiring data, you can create a small mock DataFrame using Python dictionaries, or use any sample CSV file (like Titanic or a dummy sales dataset).

---

## Module 1: Series and DataFrames
**Scenario:** You are tracking daily website visitors.
1. **Create a Series:** Create a Pandas Series containing the visitor counts `[150, 202, 145, 300, 250]`. Assign a custom index with the days of the week (`'Monday'`, `'Tuesday'`, etc.).
2. **Create a DataFrame:** Create a DataFrame from a dictionary representing a bookstore's inventory. It should have three columns: `Book_ID`, `Title`, and `Price`. Add at least 3 rows of data.

## Module 2: Reading and Writing Data
**Scenario:** You received a raw data dump from the engineering team.
1. **Selective Reading:** Write the code to load a file named `sales_data.csv`, but *only* load the columns `Order_ID`, `Date`, and `Total_Amount`. 
2. **Exporting Clean Data:** Assume you have a DataFrame named `df_clean`. Write the code to export this DataFrame to an Excel file named `final_report.xlsx` without including the integer index.

## Module 3: Inspecting and Summarizing
**Scenario:** A client just emailed you a new dataset, and you need to understand it quickly.
1. **Quick Check:** Write the commands to view the first 10 rows and the last 5 rows of a DataFrame.
2. **Data Profiling:** What single Pandas method would you use to see the data types of all columns and check how many non-null values exist?
3. **Statistical Distribution:** You have a `Salary` column. Write the code to find the mean, median, minimum, and maximum salary in one go.

## Module 4: Selection and Indexing
**Scenario:** You need to extract specific records for an audit.
1. **Position-Based (`.iloc`):** Extract the 5th, 6th, and 7th rows of a DataFrame, but only the first two columns.
2. **Label-Based (`.loc`):** Assuming your DataFrame has an index of Employee IDs (e.g., 'E01', 'E02'), extract the `Department` and `Salary` columns specifically for employees 'E05' and 'E12'.

## Module 5: Filtering (Boolean Indexing)
**Scenario:** The Marketing team needs a highly specific list of users.
1. **Single Condition:** Filter a DataFrame to show only customers where the `Country` is `'Canada'`.
2. **Multiple Conditions:** Filter a DataFrame to find customers where the `Country` is `'Canada'` **AND** the `Age` is greater than 30. 
3. **Using `.isin()`:** Filter a DataFrame to find all transactions that occurred in `['New York', 'London', 'Tokyo']`.

## Module 6: Handling Missing Data
**Scenario:** Your database export has missing values because of a system glitch.
1. **Identify the Gaps:** Write the code to count exactly how many missing values exist in each column of your DataFrame.
2. **Imputation:** You have a column called `Customer_Rating` with some missing values. Fill all `NaN` values in this specific column with the average (mean) rating.
3. **Dropping Rows:** Write the code to drop a row *only* if the `Email_Address` column is missing.

## Module 7: Data Transformation
**Scenario:** You need to prep data for a machine learning model.
1. **Renaming:** Rename the column `cust_ID` to `Customer_ID` and `txn_amt` to `Transaction_Amount`.
2. **Calculated Columns:** You have columns `Price` and `Tax_Rate`. Create a new column called `Final_Cost` which is `Price + (Price * Tax_Rate)`.
3. **Custom Logic (`.apply`):** Create a function that returns "High" if a value is over 1000, and "Low" otherwise. Apply this function to a `Revenue` column to create a new `Revenue_Tier` column.

## Module 8: Grouping and Aggregation
**Scenario:** The CFO needs a quarterly performance summary.
1. **Basic Grouping:** Calculate the total (sum) `Revenue` generated by each `Region`.
2. **Multi-Column Aggregation:** Calculate the average `Salary` and the average `Years_Experience` grouped by `Department`.
3. **Advanced `.agg()`:** Group by `Store_Location`. Find the maximum `Daily_Sales` and the total count of `Employees` for each location simultaneously.

## Module 9: Merging and Joining
**Scenario:** You need to combine user demographic data with their purchase history.
1. **Inner Join:** Merge `df_users` and `df_purchases` on the `User_ID` column, keeping only users who have made a purchase.
2. **Left Join:** Merge `df_users` and `df_purchases` on `User_ID`, ensuring *all* users are kept in the final table, even if they haven't bought anything yet. 
3. **Concatenation:** You have `df_january_sales` and `df_february_sales` (both have the exact same columns). Stack them vertically into a single DataFrame.

## Module 10: Pivot Tables and Reshaping
**Scenario:** Creating a visual matrix for the executive dashboard.
1. **Pivot Table:** Create a pivot table from `df_sales`. Set the index (rows) to `Region`, the columns to `Product_Category`, and the values to the sum of `Profit`.
2. **Melting:** You have a dataset where columns are `Year_2024`, `Year_2025`, and `Year_2026`. Melt this DataFrame so you have a `Year` column and a `Value` column instead.
